.. zephyr:board:: sf32lb57_devkit_lcd

Overview
********

SF32LB57-DevKit-LCD is the initial SF32LB57X bring-up board definition.
It temporarily reuses the SF32LB52-DevKit-LCD memory, pinmux, and peripheral
configuration so that applications can be compiled while the 57x definitions
are being added.
